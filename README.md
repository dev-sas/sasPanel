## **Welcome to sasPanel!**

**sasPanel** is an open-source, modern web server control panel developed by **Md. Sajibul Alom Sajon** (<https://devsas.shop>). It is designed to provide administrators with an intuitive web dashboard and powerful command line tools to quickly deploy and manage web domains, mail accounts, DNS zones, and databases from one central place.

## Features and Services

- **Web Server:** Apache2 and NGINX with PHP-FPM
- **Multiple PHP Versions:** Support for multiple PHP versions (5.6 - 8.5)
- **DNS Server:** Bind DNS with clustering capabilities
- **Mail Services:** POP/IMAP/SMTP with Anti-Virus, Anti-Spam, and Webmail (ClamAV, SpamAssassin, Sieve, Roundcube)
- **Database Management:** MariaDB/MySQL and PostgreSQL
- **SSL Certificates:** Automated Let's Encrypt SSL support with wildcard certificates
- **Security & Firewall:** Advanced firewall with brute-force attack prevention (iptables, fail2ban, and ipset)
- **Modern User Interface:** Clean, high-performance responsive UI with custom branding and dark/light themes

## Supported Platforms and Operating Systems

- **Debian:** 13, 12, 11
- **Ubuntu:** 26.04 LTS, 24.04 LTS, 22.04 LTS

> **Note:** 64-bit operating systems on fresh installations are recommended.

## Quick Installation

To install **sasPanel** on a fresh Linux server:

### Step 1: Log In as Root
```bash
ssh root@your.server
```

### Step 2: Download & Run Installer
```bash
bash hst-install.sh
```

Follow the on-screen prompts to complete the installation. Upon completion, access your admin panel via the URL provided in the terminal output.
